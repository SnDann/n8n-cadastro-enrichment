Como testar

Exemplo de Requisição

terminal
# Dispara o webhook do n8n com um cadastro de teste
curl - X POST http://localhost:5678/webhook/novo-cadastro \ - H "Content-Type: application/json" \ -d "{
 "nome": "Maria Silva",
 "email": "maria@empresa.com",
 " ;cep": "01310100",
 "telefone": "11999990000"
 }"

# Resposta esperada (HTTP 201 Created):
{
 " ;sucesso": true,
 "mensagem": "Cadastro realizado com sucesso",
 "endere co": {
 "logradouro": "Avenida Paulista",
 " ;cidade": "São Paulo",
 "estado": "SP"
 }
}
Tecnologias

Stack Utilizada

🔄
n8n
Orquestrador low-code self-hosted. Fluxo exportável em JSON.
📮
ViaCEP API
API pública gratuita. 100% dos CEPs brasileiros dos Correios.
⚡
Node.js + Express
API interna com 5 endpoints, auth por API Key, validações defensivas.
💬
Slack Webhook
Notificação em tempo real via Incoming Webhook com Block Kit.
🐳
Docker Compose
Ambiente reproduzivel. n8n + API sobem com um único comando.
🔐
API Key Auth
Header x-api-key para comunicação server-to-server segura.
